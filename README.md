# Shadow AFK

Нативное приложение для Windows 10/11 x64 с интерфейсом Qt Quick по предоставленному HTML-макету. Данные, настройки и шаблоны хранятся на устройстве. Регистрации нет.

## Установка

Запустите `ShadowAFK_Setup.exe`, выберите папку и откройте Shadow AFK через меню «Пуск» или ярлык на рабочем столе. Для запуска без установки распакуйте `ShadowAFK_Portable.zip` целиком и откройте `ShadowAFK.exe` внутри папки `ShadowAFK`. Оба варианта содержат среду выполнения Python.

## Режимы

- **Симулятор.** Запустите цикл на вкладке «Обзор». Для тестовых движений откройте «Мониторинг», щёлкните по области предпросмотра и нажимайте WASD на этапе «В матче». Тестовые действия обрабатываются внутри окна Shadow AFK.
- **Наблюдение.** В разделе «Шаблоны» откройте скриншот Fortnite, выделите характерную область, выберите состояние и сохраните шаблон. Для готового фрагмента укажите ширину полного кадра, из которого он вырезан. Встроенные шаблоны покрывают лобби, поиск матча, подключение, ожидание игроков, игру, выбывание и режим зрителя. Для завершения цикла добавьте шаблон экрана «Результаты».
- Откройте Fortnite в оконном режиме без рамки. В «Мониторинге» найдите и выберите окно игры, запустите наблюдение и вернитесь в Fortnite. Программа получает видимые пиксели, пока игра на переднем плане, и подтверждает состояние по трём последовательным совпадениям. Окончание матча засчитывается после подтверждённого экрана результатов.
- **Награды.** Введите цели и подтверждайте прогресс вручную. История сохраняет значения до и после и связывает правки с активной сессией. Средние считаются по сессиям наблюдения с подтверждёнными изменениями. Сравнение снимков до и после доступно на этой же вкладке.
- **Диагностика.** «Мониторинг» показывает доступность кадра, кандидата, совпадение и отсутствующие шаблоны. В «Шаблонах» можно настроить порог для состояния и область поиска. ROI задаётся четырьмя долями кадра слева, сверху, справа и снизу от 0 до 1. Пустое поле использует весь кадр.
- **Статистика.** Переключайте данные наблюдения и симуляции. Экспорт CSV включает обе категории сессий.
- **Управление.** Ctrl+B ставит сессию на паузу. По умолчанию Ctrl+Alt+Q останавливает её. На Windows аварийная остановка работает глобально, если сочетание свободно. Ctrl+B и вариант Ctrl+C работают в окне приложения. Закрытие окна при доступном трее скрывает его, пункт «Выход» завершает приложение.

Наблюдение использует обычный захват рабочего стола и запрос имени исполняемого файла для выбора окна. Приложение не отправляет ввод в Fortnite. Совместимость с античитом и точность распознавания на реальных кадрах требуют отдельной проверки на Windows. [Позиция Epic о сторонних программах](https://www.epicgames.com/help/c-34254770/c-40491939/will-i-be-banned-if-i-use-third-party-software-with-fortnite-a15028164)

## Сборка Windows x64

- **Docker Desktop на Mac.** Запустите Docker и выполните `./build-windows-docker.sh`. Контейнер Linux x86-64 запускает Windows Python и Inno Setup через Wine. Скрипт проверяет запуск упакованного приложения, установку и удаление в Wine. Результаты появляются в `release/`. На Apple Silicon запуск Wine в контейнере зависит от эмуляции x86-64. Если Wine не запускается, используйте сборку в GitHub Actions или Windows.
- **Windows.** Установите Python 3.12 x64 и Inno Setup 6.4.3, затем запустите `build.bat`. Готовое приложение находится в `dist/ShadowAFK/`, установщик в `release/`.
- **GitHub.** Отправьте исходники в репозиторий. В Actions откройте workflow **Windows x64** и скачайте артефакт **ShadowAFK-Windows-x64** после успешной сборки. Workflow также проверяет установку, запуск и удаление на Windows.

## Проверка исходников

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt pytest
python -m pytest -q
python run.py --smoke
```

На macOS исходники можно запустить командой `python run.py` для просмотра интерфейса и симуляции. Захват Fortnite доступен на Windows.

## Telegram

В настроенной сборке откройте «Telegram», нажмите «Привязать Telegram» и затем Start в личном чате с общим ботом. Статус обновится автоматически. Параметр ссылки одноразовый и действует 10 минут. При повторном запуске Shadow AFK восстанавливает сессию установки из локального профиля Windows.

Для события победы добавьте в «Шаблонах» вырезку реального баннера «Королевская победа» и выберите соответствующий тип. Уведомление требует трёх последовательных совпадений с порогом не ниже 95% во время отслеживаемого матча. Проверка связи отправляет уведомление после пяти минут без heartbeat, в том числе при закрытии приложения.

Владельцу проекта нужно один раз [развернуть Supabase и подключить общего бота](supabase/README.md). Пользователи приложения выполняют только привязку.
